# AI4X 2027 - website preview

**This is a preview of a website under construction, not the AI4X 2027 website.**

- Live preview: https://nadjacordarov.github.io/ai4x-2027-review/
- Snapshot: 2026-10-16, generated from the private build repository (source 3833cdf).

## Please note

- **The legal pages are placeholders.** The Imprint, the Privacy Policy and the
  Cookie Policy contain placeholder or tool-generated text that has not been
  legally reviewed. They are not valid legal documents.
- Text marked `[PLACEHOLDER]`, `[VERIFY ...]`, `[confirm ...]` or `[??]` is
  unconfirmed and will change.
- Some links and forms are placeholders (`#`) until their real targets exist.
- The site is not meant to be found by search engines: every page carries
  `<meta name="robots" content="noindex, nofollow">` and `robots.txt`
  disallows all crawling. This is not access control: anyone with the link can
  read it.
- Google Maps loads only after consent in the cookie banner. Nothing else on
  the preview contacts another server.

## Do not edit this repository

It is a static export of a WordPress site. Every publish replaces the entire
history with a single new snapshot commit, so changes made here are lost.
